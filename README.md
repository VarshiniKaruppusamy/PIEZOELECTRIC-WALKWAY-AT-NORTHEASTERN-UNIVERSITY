# Piezoelectric Walkway — Smart City Energy Analytics

## Project Overview
Engineered a functional prototype embedded with piezoelectric 
sensors to capture and analyze real-time energy generation 
from pedestrian foot traffic, demonstrating potential for 
smart city infrastructure.

## Problem Statement
Urban spaces consume enormous energy. This project explored 
whether pedestrian foot traffic could be harvested as a 
supplementary energy source for public infrastructure.

## My Role
- Designed and executed performance testing framework
- Collected and cleaned real-time sensor data
- Conducted statistical analysis to validate energy efficiency
- Built Excel reporting model to project cost savings and ROI
- Documented findings and presented recommendations

## Tools & Technologies
- Excel (Advanced Analysis, Pivot Tables, Charts)
- Piezoelectric Sensors
- Statistical Data Modeling
- Data Visualization

## Key Outcomes
- Validated real-time energy generation efficiency metrics
- Produced ROI analysis demonstrating cost-saving potential
- Documented scalability recommendations for public spaces

## Business Impact
Translated raw sensor data into a cost-benefit analysis 
showing potential energy savings for smart city deployments — 
effectively an ROI report for non-technical stakeholders.
